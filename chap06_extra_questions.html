第6章 追加問題

データセット

SSDSE-社会生活（SSDSE-D-2023）を使う。 都道府県別・男女別の自由時間活動と生活時間のデータで、教育用標準データセットとして 独立行政法人 統計センターから公開されている。

ダウンロード: https://www.nstac.go.jp/use/literacy/ssdse/

このデータには 5 つの行動分類の総数（行動者率、%）が含まれている：

  • 学習・自己啓発・訓練の総数
  • スポーツの総数
  • 趣味・娯楽の総数
  • ボランティア活動の総数
  • 旅行・行楽の総数

ここでは「男女の別」が 0_総数（男女計）の 47 都道府県分（全国を除く）を対象とする。

開発側の問題

教科書 6 章のクラスタリング手法を多次元データに拡張する。授業で扱った クラスタ数 n の客観的評価指標（エルボー法・シルエットスコア）を活用する。

F1. 5 つの行動分類でのクラスタリングと n の選択

教科書 6 章（コード 6-3, 6-9, 6-16）では合計特殊出生率と世帯年間収入の 2 変数で n=2, 3, 4 を試したが、ここでは 5 変数に拡張する。 2 次元なら散布図で目視判断できたが、5 次元では散布図に描けないため、 授業で扱った客観指標を使うしかない。

  1. SSDSE-D から 47 都道府県・男女総数のデータを取り出し、上記 5 列を StandardScaler で標準化せよ（コード 6-3 と同じ手順）。

    そのうえで、5 列の標準偏差（生スケール、標準化前）を求めて表示せよ。 今回のデータは「すべて行動者率（%）」で単位は同じだが、標準偏差は 最小と最大で約 2 倍以上の差がある。「単位が同じだから標準化は不要では ないか」という考え方がなぜ誤りか、k-means が用いるユークリッド距離 との関係から説明せよ。

  2. n=2 から n=10 まで KMeans(n_clusters=n, n_init=10, random_state=0) で繰り返しクラスタリングし、各 n の inertia と silhouette score を計算してそれぞれ折れ線グラフで可視化せよ。

  3. 上の 2 つのグラフから、採用する n を 1 つ選べ。ただし、教科書 6 章 本文のデータでも本問のデータでも、エルボーは明確には現れないことが 知られている。

    • エルボーが見えにくい理由を、「クラスタの分布が連続的である場合の inertia の減り方」という観点から説明せよ。
    • 今回のデータで silhouette score が支持する n と、解釈可能性の観点を 加味して採用する n を決め、選んだ根拠を述べよ。

F2. クラスタごとの特徴と解釈可能性

問 F1 で採用した n でクラスタリングした結果について、各クラスタの 特徴を読み取る。

  1. クラスタごとに 5 列それぞれの平均を求めよ（コード 6-4, 6-10, 6-17 と 同様）。さらに、各クラスタに所属する都道府県の一覧を出力せよ （コード 6-8, 6-15, 6-21 と同様の手順）。

  2. クラスタごとに、他のクラスタと比べて値が大きい / 小さい行動分類を それぞれ 1〜2 個挙げ、そのクラスタの特徴を 1 文で表現せよ （例：「学習・自己啓発が高く、ボランティアが低いクラスタ」）。

  3. 採用した n で作ったクラスタの中に、地理的に近い都道府県が まとまっているもの、または何らかの社会的意味で説明しやすい まとまりがあるか確認せよ。あれば 1 つ取り上げて説明せよ。 なければ「特に地理的・社会的に説明できるまとまりは見当たらない」 と書き、それが採用した n の評価にどう影響するかを述べよ。

分析・企画側の問題

ここでは教科書 6 章本文のデータ（合計特殊出生率 × 世帯年間収入、47 都道府県） を使う。教科書では n=2, 3, 4 を順に試して終わっているが、授業で扱った inertia とシルエットスコアを使って、教科書の選択を事後的に検証する。

補助コードと計算結果

教科書のコード 6-18 までを実行した直後に、以下のコードを追加して n=2 から n=10 までの 2 つの指標を計算する。このコードはそのまま使ってよい。

from sklearn.metrics import silhouette_score
import matplotlib.pyplot as plt
import japanize_matplotlib

ns = range(2, 11)
inertias, sils = [], []
for n in ns:
    km = KMeans(n_clusters=n, n_init=10, random_state=0)
    labels = km.fit_predict(birth_clust_sc)  # コード 6-3 で作った標準化済みデータ
    inertias.append(km.inertia_)
    sils.append(silhouette_score(birth_clust_sc, labels))

fig, axes = plt.subplots(1, 2, figsize=(10, 4))
axes[0].plot(list(ns), inertias, marker="o")
axes[0].set_xlabel("n"); axes[0].set_ylabel("inertia"); axes[0].set_title("エルボー法")
axes[1].plot(list(ns), sils, marker="o", color="orange")
axes[1].set_xlabel("n"); axes[1].set_ylabel("silhouette"); axes[1].set_title("シルエットスコア")
plt.tight_layout(); plt.show()

G1. 教科書の選択を事後的に検証する

教科書はクラスタ数を n=2 → n=3 → n=4 と試して終わっている。 これが妥当な止め方だったかを、上の指標を使って評価する。 （この問題では、文章で答えればよく、追加のコードを書く必要はない。）

  1. シルエットスコアは n=2〜10 のうち、どの n で最大か。その値はいくつか。 教科書が試した n=2, 3, 4 の範囲は、この客観指標から見て適切な範囲 だったと言えるか、述べよ。

  2. inertia の表を見ると、明確な「肘」が見当たらない。 それでも n=4 と n=5 の間に「緩い肘」があると主張するとしたら、 どの数値の変化を根拠にできるか。具体的に n=3→4 の減り方と n=4→5 の 減り方を比較して、自分の言葉で説明せよ。

  3. 仮にあなたが分析担当者で、上司から「都道府県を意味のあるグループに 分けて報告してほしい」と頼まれたとする。上の 2 指標と、教科書 6-12, 6-19 の散布図（n=3 と n=4 の場合）の見え方を踏まえて、採用する n は 3 か 4 かを判断し、上司に説明する 3〜5 文を書け。 「シルエットが大きいから」だけで終わらせず、報告先が 使える分け方になっているかという観点を含めること。

G2. シルエットが「ぱっとしない」ことを依頼者にどう説明するか

教科書本文のデータでシルエットスコアの最大値は約 0.39 にとどまる。 これは授業のデモ（4 クラスタ・各 5 点で 0.68 程度）と比べて低い値である。

  1. シルエットスコアが 0.39 と 0.68 ではクラスタの「分かれ具合」がどう 違うか、授業の説明（1 に近いほど自分のクラスタに馴染んでいる、0 に 近いほど境界上）を踏まえて、Python を知らない人にも分かるように 2〜3 文で書け。

  2. 分析を依頼した相手から「で、結局この 47 都道府県は 4 つに分かれて いると言っていいんですか？」と聞かれた場面を想定する。 この問いに「はい / いいえ」だけで答えず、シルエットの値（約 0.39）が 意味することを踏まえて、誠実な回答を 3〜5 文で書け。 「言い切れること」と「言い切れないこと」の両方を含めること。

  3. 上の回答に続けて、依頼者から「じゃあ追加でどんな情報があれば、 もっとはっきり分けられるんですか？」と聞かれたら、どう答えるか。 現在のデータ（合計特殊出生率と世帯年間収入の 2 変数）の限界を ふまえて、別の変数の追加や別の手法の検討を含めて、2〜3 個の提案を 箇条書きで示せ。
