相関係数と有意性検定

少数データの相関は、
あてにならない

下の散布図はまったく無関係な2つの変数（真の相関 ρ = 0）から乱数で作っています。それでもデータ点が少ないと、直線はきれいに引け、相関係数 r は簡単に大きな値になります。スライダーとボタンで、その「偶然の相関」を自分の手で確かめてください。

「有意」と出る割合
|r| ≧ 臨界値（有意と判定される領域） 非有意の領域 いまの標本の r

n を小さいまま「新しい標本を引く」を何度か押すと、r が毎回大きく跳ねるのが見えます。ρ = 0（無相関）でも n が小さいほど r の分布は横に広がり、偶然だけで見かけの相関が生まれます。逆に n を増やすと分布は 0 に収束し、有意判定に必要な 臨界 |r| も下がっていきます。相関を語るには、係数の大きさだけでなく データ点数 が要ることの図解です。
