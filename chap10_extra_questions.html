第10章 追加問題（傾向スコア・マッチング）

第10章「施策の効果を調べよう（傾向スコア・マッチング）」の追加問題です。 コードを動かすだけでは答えになりません。理由・仕組み・判断を自分の言葉で書いてください。

  • 開発側（F1・F2）：実装の仕組みと設計の理由を説明する問題です。
  • 分析・企画側（G1・G2）：出てきた数値を読んで、依頼者に説明・判断する問題です。

開発側は教科書の従業員データ（800名）を使います。分析・企画側は計算結果を問題文に載せてあるので、数値を読んで答えてください。

開発側

F1. ビン分けの不安定性と再現性

コード10-3で傾向スコア prop を求め、コード10-5で df["group"] = (df.prop * 20).astype(int) としてグループを作り、コード10-6でグループごとに HappyAfter の平均を取ります。ここである学生から次の質問が出ました。

教科書ではグループ4の処置群の平均が 1.723015 なのに、自分が実行すると 1.884828 になります。なぜですか？

調べると、prop は scikit-learn の版差で小数第5〜6位だけ動いていました。また、prop * 20 が整数の境界付近（整数 ±0.05）にいる従業員は約 85名 いて、グループ4の処置群はわずか 17名 でした。なお、差の平均（コード10-9）は版が変わっても約 1.55 のままです。

  1. (prop * 20).astype(int) が「切り捨て」であることを確認した上で、prop が第5〜6位で動くだけで、なぜグループ4のような小さなグループの平均が 1.723 → 1.885 と目に見えて変わるのかを、上の「境界付近85名」「処置群17名」という数値を使って説明せよ。
  2. グループごとの平均は揺れるのに、全グループの差の平均（コード10-9、約1.55）はほぼ動かない。この「揺れるのに頑健」が両立する理由を、境界をまたいだ人がどのグループへ移動するか（移動先はどこか）に着目して説明せよ。
  3. (prop * 20).astype(int) の代わりに pd.cut を使って境界を固定したビン分けに書き換えるコードを示せ。そのうえで、切り捨てによるビン分けと比べたときの違いを2点述べよ。

F2. マッチング集計の仕組みと NaN の本質

コード10-6では df.groupby(["group", "Treatment"])["HappyAfter"].mean().unstack("Treatment") でグループ×処置の平均表を作ります。このときグループ0とグループ19の値が NaN になります。各グループの人数は次の通りです。

group 対照群(Treatment=0) 処置群(Treatment=1)
0 20名 0名
19 0名 3名
  1. unstack("Treatment") を付けると表がどのような形（行・列）に変わるかを説明せよ。そのうえで、グループ0とグループ19が NaN を含む理由を、上の人数表をもとに説明せよ。
  2. コード10-9の difference.mean() は、グループ0・19を drop してもしなくても 1.5483 になる（pandas が NaN を自動でスキップするため）。それなのにコード10-10ではわざわざ [0, 19] を drop してから集計している。drop する理由を説明せよ。 ヒント：コード10-10は treated.mean() と untreated.mean() を別々に計算している。drop しないと、どのグループのどの値が混入し、treated平均と untreated平均がそれぞれどちらの向きに歪むか、次の数値を使って具体的に示せ。
    • treated平均：drop なし 2.903 / drop あり 2.733
    • untreated平均：drop なし 0.982 / drop あり 1.185
  3. コード10-3の prop_score = model.predict_proba(X) の戻り値は (800, 2) の形をしている。df["prop"] = prop_score[:, 1] で [:, 1] を取る理由を、model.classes_ が何を返すかと絡めて説明せよ。 さらに、同じパイプラインを別の顧客データ（650名・閲覧時間 Browsing を含む）に適用すると、NaN になるのはグループ0だけになり、グループ19は対照群1名・処置群19名で両群がそろう。教科書データでは0と19の両方が NaN なのに、データが変わると NaN の位置が変わるのはなぜかを説明せよ。

分析・企画側

G1. 傾向スコアの意味とマッチングの動機

ある会社が、希望者向けの研修の効果を調べました。従業員は 800名、うち研修を受けた人（処置群）が 328名、受けていない人（対照群）が 472名 です。各従業員について、ロジスティック回帰で求めた prop（傾向スコア、0〜1の値、範囲は約 0.006〜0.961）が計算されています。

  1. ある従業員の prop は 0.66 でした。これを「この人は研修で幸福度が上がる確率が66%だ」と説明するのは正しいか。誤っているなら、prop が本当は「何の確率」なのかを明示して、正しい説明に直せ。
  2. 研修を受けた328名の研修後の幸福度の単純平均と、受けていない472名の単純平均を、そのまま引き算して「研修の効果」と呼んではいけない。その理由を、両群の背景（年齢・勤続年数・元々の幸福度など）の偏りという観点から説明せよ。授業で出た「CMを見たグループ／見ていないグループ」の例にも触れてよい。
  3. prop が近い人どうしをグループにして比べることで、両群の「何をそろえている」のか。逆に、このやり方でもそろえられない要因（データに入っていない要因）の例を2つ挙げよ。

G2. 効果の解釈・予想外の結果・依頼者への説明

傾向スコア・マッチングで2つの案件を分析したところ、マッチング後の「差の平均」は次のようになりました。

案件 処置 差の平均
従業員研修（800名） 研修の受講 約 +1.55（研修後の幸福度が、似た背景の未受講者より平均1.55高い）
新サイトデザイン（顧客650名） 新デザインの表示 約 −33.56円（マイナス）
  1. 従業員研修の「+1.55」を、Python を知らない研修担当の上司に1〜2文で報告せよ。あわせて、「研修に効果があった」と断定してよいか、断定するにはどんな前提（仮定）が必要かを一文で添えよ。
  2. 新サイトデザインの案件で、差の平均が −33.56円 とマイナスになった。依頼者から「新デザインは失敗だったということですか？」と聞かれた場面を想定し、言い切れること・言い切れないことの両方を含む誠実な回答を3〜4文で書け。
  3. 続けて依頼者から「もっとはっきりさせるには、どんなデータがあればよいですか？」と聞かれた。データに入っていない要因をそろえられていない可能性を踏まえ、あると分析が改善する情報を2〜3個、箇条書きで挙げよ。
