第8章 追加問題

追加問題について

本章の追加問題は、章末問題（問1〜問3）で使った都道府県データ（chapter08_exercise.xlsx）ではなく、教科書本文のデータ chapter08.xlsx を使う。これは「購入」（購入意欲のレベル 0・1・2・3 の4クラス）を、7個の特徴量（年齢・閲覧時間・気温・収入・貯金・距離・体力）から予測するデータである。

まず教科書コード 8-1〜8-8 を実行して、データの読み込みと基本のランダム・フォレストが動く状態にしておくこと。

F1. ランダム・フォレストのテスト正解率を上げる

教科書コード 8-6 では、次の設定でランダム・フォレストを学習している。

model_rf = RandomForestClassifier(
    max_depth=4,
    random_state=0
)

この設定（n_estimators は既定値の 100）では、学習用 約88.2%・評価用 約85.2% という結果になる。この章の追加問題では、評価用（テスト）の正解率をできるだけ高くすることを目指して、その過程で何が効いているのかを説明してもらう。

  1. まずコード 8-6・8-7・8-8 をそのまま実行し、評価用・学習用の正解率を記録せよ。次に、RandomForestClassifier の引数 max_features の既定値は 'sqrt' である。今回の特徴量は7個だが、max_features='sqrt' のとき、1回の分岐で実際に候補となる特徴量は何個かを答えよ。そのうえで、授業スライド（ランダム・フォレストの仕組み）を踏まえ、なぜランダム・フォレストはわざわざ分岐ごとに一部の特徴量しか使わないのかを、「木をばらけさせる」「平均する」という観点から自分の言葉で説明せよ。

  2. max_depth=4, n_estimators=200 は固定したまま、max_features を 'sqrt' → 0.5 → 0.7 → None（＝全特徴量を使う）と変えて、それぞれの評価用正解率を求めて表にせよ。観察された傾向を述べ、このデータではなぜ「分岐で使う特徴量を増やす」方向が有利になりやすいのかを、特徴量の個数（7個）と各特徴量の情報量という観点から考察せよ。

  3. max_depth・n_estimators・max_features を自分で調整し、評価用正解率がコード 8-6 のベースライン（約85.2%）を明確に上回る設定を見つけよ（目安：88%以上）。最終的に採用した設定と、そのときの学習用・評価用の正解率を示せ。

  4. 評価用正解率を上げていくと、学習用正解率との差はどう動いたか。そのうえで次の2点を説明せよ。

    • 1回の train_test_split（random_state=0）での評価用正解率が高いことは、本当に「良いモデルができた」と言い切れるか。1つのテスト分割に合わせて調整を続けることの危うさは何か。
    • 改善が「たまたま」ではなく本物だと、より誠実に確かめるにはどうすればよいか。具体的な方法を1つ挙げ、その方法だと何が分かるのかを説明せよ。

G1. 「どの要因が効いているか」を読み、依頼者に伝える

教科書コード 8-11・8-12 では、ランダム・フォレストの feature_importances_（特徴量の寄与）を計算して棒グラフにした。あなたはこのモデル（購入意欲 0〜3 を予測）の分析を、Python を知らないマーケティング担当者から依頼されたとする。

下のコードはそのまま実行してよい。実行すると、寄与のランキングと、参考として「購入」と各変数の相関が表示される。

import pandas as pd
from sklearn.ensemble import RandomForestClassifier
import sklearn.model_selection

X = pd.read_excel("data/chapter08.xlsx")
y = X["購入"]
X2 = X.drop("購入", axis=1)
X_train, X_test, y_train, y_test = \
    sklearn.model_selection.train_test_split(X2, y, random_state=0)

model_rf = RandomForestClassifier(max_depth=4, random_state=0)
model_rf.fit(X_train, y_train)

# 寄与のランキング
imp = pd.DataFrame({"変数": X2.columns, "寄与": model_rf.feature_importances_})
print(imp.sort_values("寄与", ascending=False).to_string(index=False))

# 参考：購入と各変数の相関
print(X.corr()["購入"].drop("購入").sort_values(ascending=False).round(3))

  1. 寄与のランキングでは「閲覧時間」が 0.312 で最も大きい。feature_importances_ が何を測っている数字なのかを、Python を知らない担当者にも分かる言い方で説明せよ。あわせて、「閲覧時間の寄与が一番大きい」という事実は、「閲覧時間が長いほど購入意欲が高い／低い」のどちらを意味するのか、この寄与の数字だけから言えるかどうかを述べよ。

  2. 寄与では「閲覧時間」が1位だが、相関の表を見ると、購入と最も強く（正の方向に）関係しているのは「体力」(+0.595) と「貯金」(+0.569) で、「閲覧時間」の相関はむしろ負(−0.496)である。担当者から「結局どっちが正しいの？」と聞かれた。寄与と相関が食い違うことがあるのはなぜか、それぞれの数字が何を捉えているのかを説明せよ。

  3. 担当者は「じゃあ閲覧時間を増やせば購入が増えるんだね」と言っている。この分析から (a) 自信をもって言えること と (b) 言えないこと（因果・効果の向き・「閲覧時間を増やせば購入が増える」と断定できるか）をそれぞれ挙げ、担当者に何をどう助言するかを 2〜3 文で書け。
