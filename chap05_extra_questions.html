開発側の問題（F）

F1. fit() は何を計算しているのか

コード 5-6 では次のコードを実行しています。

x = df[["広告費"]]
y = df[["売上高"]]

model = LinearRegression()
model.fit(x, y)

print(model.coef_)
print(model.intercept_)
print(model.score(x, y))

出力は以下のとおりでした。

[[5.50471155]]
[-250.99471334]
0.7211643562957983
  1. model.fit(x, y) は何をしているメソッドか、「傾き」「切片」「データから計算する」という3つのキーワードをすべて使って説明せよ。「モデルを学習する」という表現だけでは不十分である。
  2. model.coef_ と model.intercept_ はそれぞれ何を表すか答えよ。今回の出力 [[5.50471155]] と [-250.99471334] が、回帰式 売上高 = a × 広告費 + b の a, b にどう対応するかも説明せよ。
  3. sklearn の LinearRegression には fit()・score()・predict() の3つのメソッドがある。それぞれの役割を1行ずつ説明せよ。

F2. 単回帰から重回帰へ — R² が上がる理由

コード 5-6・5-7・5-9 の結果を並べると次のようになります。

モデル 説明変数 R²
単回帰① 広告費 0.721
単回帰② 距離 0.114
重回帰 広告費＋距離 0.930
  1. 単回帰① の R²=0.721 はどのような意味か、「売上高のばらつき」「説明できる割合」という言葉を使って説明せよ。
  2. 重回帰のR²が単回帰①より高い（0.721 → 0.930）のはなぜか。「距離」の追加がなぜ説明力を上げるのかを、コード 5-7 の結果（R²=0.114）もふまえて説明せよ。
  3. 説明変数を増やせば R² は必ず上がる。この性質が持つ「落とし穴」を説明し、それを回避するために使われる指標（調整済み R² など）について調べて述べよ。

分析・企画側の問題（G）

G1. 広告費と売上高の関係を店長に報告する

コード 5-6 の結果、広告費と売上高の関係は次の式で表されました。

売上高 = 5.50 × 広告費 − 251
（R² = 0.721）
  1. この回帰式の「傾き 5.50」は現実にどういう意味か、「広告費を1万円増やすと」という文脈で説明せよ。（売上高・広告費の単位はともに万円とする）
  2. R²=0.721 という値は、店長に「信頼できる予測式か」を説明するうえでどう解釈すればよいか。「完全に信頼できる」でも「まったく信頼できない」でもない立場から、自分の言葉で述べよ。
  3. 広告費を現在の50万円から55万円に増やしたとき、売上高はいくらと予測されるか計算し、その予測値を「そのまま信じてよいかどうか」についても意見を述べよ。

G2. 重回帰モデルで「言えること」と「言えないこと」を区別する

コード 5-9 の重回帰結果は次のとおりです。

売上高 = 5.91 × 広告費 − 0.74 × 距離 − 25.1
（R² = 0.930）
  1. 係数「−0.74」は現実にどういう意味か説明せよ。「店が最寄り駅から1m遠ざかると」という文脈で答えること。
  2. このモデルから「確実に言えること」を2点、「言いたくなるが実は言えないこと（または慎重さが必要なこと）」を2点、それぞれ挙げよ。
  3. 広告費20万円・最寄り駅距離500mの店舗の売上高を予測せよ。また、この予測を根拠に「広告費を増やすべきか」という経営判断をするとしたら、追加でどんな情報が必要か述べよ。
